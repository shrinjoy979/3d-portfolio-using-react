# 🚀 3D Portfolio Using React

A modern and interactive **3D Portfolio Website** built with **React**, **Three.js**, and **React Three Fiber**. This project showcases a developer portfolio with smooth animations, responsive design, and immersive 3D experiences to create an engaging user interface. The project follows the popular 3D portfolio architecture using React, Vite, and Three.js. :contentReference[oaicite:0]{index=0}

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shrinjoy979/3d-portfolio-using-react.git
```

Go to the project directory

```bash
cd 3d-portfolio-using-react
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
